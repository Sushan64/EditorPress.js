# EditorPress.js

EditorPress.js is an open source rich text editor built with JavaScript and React. It provides a clean writing experience with common editing tools, media support, tables, and multiple export formats.

**Live demo:** [editorpress.vercel.app](https://editorpress.vercel.app)

## Features

- Automatically turns URLs into links while you type
- Supports Markdown commands
- Converts text into code blocks with syntax highlighting
- Supports text alignment, ordered lists, and unordered lists
- Exports content as JSON, Markdown, or HTML
- Inserts images from your device or from a URL
- Resizes images and supports image captions and alternative text
- Adds and edits tables
- Supports common formatting such as bold, italic, and underline
- Includes undo and redo
- Supports font sizes and heading levels

## About

EditorPress.js is free to use in personal and open source projects. It is designed to make rich text editing simple while giving users control over their content and export format.

The project uses:

- [React](https://react.dev/)
- [Tiptap](https://tiptap.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vite.dev/)

## Installation

Make sure that Node.js and Git are installed on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/Sushan64/EditorPress.js.git
cd EditorPress.js
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to use the editor.

### Other commands

Build the project for production:

```bash
npm run build
```

Check the project with ESLint:

```bash
npm run lint
```
